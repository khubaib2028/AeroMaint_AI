AeroMaint AI — Phase 13 (Final)

Run from the project root (the folder containing requirements.txt):

1. python -m venv .venv
2. .\.venv\Scripts\Activate.ps1
3. pip install -r requirements.txt
4. python seed.py
5. python train_model.py
6. uvicorn app.main:app --reload

Open: http://127.0.0.1:8000

Important:
- requirements.txt is in the project root.
- Do not run commands from an extra nested project folder.
- Phase 8 through Phase 13 dashboard loaders are designed to load independently.
- Phase 13 adds AI Fleet Command & Decision Center on top of existing fleet health,
  maintenance execution, analytics and inventory intelligence.
- Synthetic SIH MVP data is included for demonstration.
